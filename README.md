# SketchSummit

Serves developers with a lightweight CLI tool for generating and tracking swaps and liquidity pools in real time.

With SketchSummit, you get a lightweight tool that stays out of your way.

**What you get**

- Serves developers with a lightweight
- CLI tool for generating and
- tracking swaps and liquidity pools

## Key Features

- Serves developers with a lightweight
- CLI tool for generating and
- tracking swaps and liquidity pools

## Technology Stack

- typescript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchSummit.git`
2. `cd SketchSummit`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
